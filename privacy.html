Privacy Policy

Draft for developer review · November 19, 2026

Information processed

The application processes Discord user, server and channel identifiers, member names and roles, server message content for security checks, message and join timing, moderation actions and reasons, and game interactions. Birthday celebrations use the selected member's Discord avatar and track wishes in memory; the current code does not store birth dates.

Stored information

SQLite stores server and member identifiers, moderation actions, reasons and timestamps; game wins and losses; and server game settings including channel, interval, enabled status and last-run time.

Message handling

Messages are inspected for links and spam. Messages containing detected links may be deleted and up to 1,500 characters forwarded to the server's owner-setting channel for review. Approved content may be reposted. Moderation logs and alerts may also appear in that channel. Discord messages can remain there until deleted. The application sends direct messages for welcomes and moderation notifications.

Purpose and access

Information supports moderation, link review, spam and raid alerts, games and celebrations. Game scores can be displayed to server members. Moderation functions in the current code can be accessed by the server owner and configured bot owner, subject to role checks. The application runs on Wispbyte and communicates with Discord; those services have their own privacy policies.

Retention and deletion

The current code has no automatic expiration or deletion command for SQLite records. Removing the bot does not automatically erase records or Discord messages. A retention schedule and a deletion-request process must be established before public release.

Contact and rights

Developer: NATHAN. A support contact and request procedure must be confirmed before public release. Users may have applicable rights to access or delete personal data.

See Discord's Privacy Policy.
